# Unterm 最新工作区与 v0.57.4 成熟度对比

日期：2026-08-01  
基线：`v0.57.4`（本机官方安装版，实例 `charlie`）  
候选：`353588d7` 加当前工作区修复

## 结论

候选版本保留了 v0.57.4 的 14 个 MCP 命名空间、99 个方法和核心交互，并针对内核调整后出现的 UI/功能回退做了恢复。性能优化集中在输入热路径、Windows 消息循环、Agent 状态采集和左侧标签栏重绘；恢复动画和状态新鲜度时没有撤销这些优化。

## 对比矩阵

| 维度 | v0.57.4 | 候选版本 | 处理结果 |
| --- | --- | --- | --- |
| MCP 功能面 | 14 命名空间、99 方法 | 相同 | 保持协议与 CLI 能力不变 |
| 自检 | 长期运行实例 8/8；后台新窗口 7/8 | 后台新窗口 7/8 | 唯一失败均为宿主前台权限导致的 `capture.window`，无版本差异 |
| Ghost completion | 每次重算复制最多 512 条全局历史；首次 Agent flag 补全可读磁盘 | 有界扫描；清单后台加载；后台完成整表、写锁内只换表 | 输入热路径不做磁盘 IO，不长时间占写锁 |
| Agent 状态 | 2 秒新鲜度、最多 16 个并发采集 | 2 秒新鲜度、最多 4 个并发采集 | 保留可见新鲜度，并把并发压力降低 75% |
| 左侧标签栏元数据 | 每次重绘重新采集所有标签 | 350 ms 元数据缓存，key 覆盖 tab、pane、title、active | 高频滚动/动画重绘复用快照 |
| 左侧标签栏元素树 | 呼吸动画每步重建 | 5 秒兜底缓存且 key 含量化呼吸步 | 同一步复用，状态变化仍会失效 |
| Working 状态提示 | 3.2 秒、4 步呼吸提示 | 同样的 3.2 秒、4 步提示 | 恢复成熟视觉反馈 |
| 标签重命名 | 同行、同按钮、近距离双击打开内联重命名 | 恢复；明确 500 ms/8 px 边界并有单测 | 防止跨行或拖动误触 |
| 标签拖动 | 小幅抖动不触发重排 | 保持 4 px 启动阈值 | 点击与拖动兼容 |
| Windows 剪贴板 | 在窗口事件线程发起异步读取 | 恢复该线程亲和性 | 避免右键粘贴间歇失效 |
| Windows WndProc | 生命周期日志可进入同步文件 IO | 仅 `UNTERM_WINPROC_LOG=1` 时启用 | 默认移除消息循环磁盘阻塞 |
| 实例存活判断 | 无法打开进程即视为死亡 | 仅 `ERROR_ACCESS_DENIED` 视为仍存活；无效 PID 清理 | 兼顾受保护进程与陈旧实例 |

## UI 验收点

- 标签单击激活、4 px 后才进入拖动重排。
- 同一标签、同一鼠标按钮、坐标差不超过 8 px、时间不超过 500 ms 才触发重命名。
- 重命名 Enter 应用；空值恢复自动标题；Esc 取消。
- Working Agent 的状态点继续呼吸，但动画帧复用 350 ms 内的元数据，不重复做进程检查。
- 右键有选择时复制并清除；无选择时粘贴。
- 左侧项目分组、折叠、搜索、滚动锚点、未读/进度/Agent 状态均保留。

## 发布构建实测

测试对象均为 release 构建、单窗口单 pane，并在同一台 Windows 主机交替启动三次。首次生成的新二进制会触发 Defender/文件缓存预热，因此采用受控重复样本的中位数。

| 指标 | v0.57.4 官方版 | 候选 release | 结果 |
| --- | ---: | ---: | --- |
| MCP ready 中位数 | 78.6 ms | 82.5 ms | +3.9 ms，约 +5.0% |
| 稳态 `server.health` 中位数 | 约 19.5 ms | 约 19.4 ms | 等同 |
| 启动后工作集内存中位数 | 114.2 MB | 100.3 MB | -13.9 MB，约 -12.2% |
| 启动后私有内存中位数 | 161.9 MB | 162.9 MB | +1.0 MB，约 +0.6% |

继续空闲并执行同样的 headless UI 抓取后，工作集为 119.1 MB（v0.57.4）与 105.9 MB（候选），趋势一致。两版生成的 120×31、1080×589 终端渲染 PNG 逐字节相同，SHA-256 均为 `7470E7ECDE9C03E17691F6D51CE2989AACF82AD49A832B7A064569A7AF37DEE0`。
